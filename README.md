# LRCLIB Lyrics for MusicBee

MusicBee の歌詞プロバイダとして LRCLIB から再生中の曲の歌詞を取得し、同じフォルダーに同名の歌詞ファイルも保存するプラグインです。同期歌詞は `.lrc`、非同期歌詞は `.txt` として保存します。

本プラグインは LRCLIB API を利用する独立したプラグインで、LRCLIB の公式プラグインではありません。

## 機能

- LRCLIB の `/api/get` を使ったメタデータ検索と `/api/search` によるフォールバック検索
- 同期歌詞のみを取得するモード（既定）と、非同期歌詞も許可するモード
- 同期歌詞は同名 `.lrc`、非同期歌詞は同名 `.txt` として保存
- 歌詞を取得する条件を選択可能
- 埋め込み歌詞の削除・上書き設定
- 検索候補が複数あるときの手動選択による誤一致防止
- MusicBee の歌詞プロバイダとして登録し、歌詞パネルからの検索に対応
- MusicBee のプラグイン画面に「プラグイン情報」と「プラグイン設定」を表示し、設定はポップアップで編集可能
- プラグイン設定ポップアップのテーマを Windows 設定との同期・ライト・ダークから選択
- プラグインの表示言語を自動・日本語・英語から選択
- 同一曲への重複リクエスト抑止、LRCLIB API への直列リクエスト、レート制限への対応、既定 12 秒の通信タイムアウト、MusicBee のログへの結果出力

非同期歌詞には同期タイムコードを付与せず、プレーンテキストの `.txt` として保存します。

## 導入方法

1. GitHub Actions のアーティファクトまたは Release からインストール用 ZIP をダウンロードし、MusicBee のプラグインインストール機能で ZIP を指定します。手動で配置する場合は、ZIP 内の `mb_LrclibLyrics.dll` を MusicBee の `Plugins` フォルダーへコピーし、MusicBee を再起動します。
2. MusicBee のプラグイン画面で「プラグイン情報」をクリックするとバージョンなどを確認できます。「プラグイン設定」をクリックすると設定項目をポップアップで編集できます。
3. MusicBee の **編集 > 設定 > タグ(2) > 歌詞** で、歌詞プロバイダ `LRCLIB` を有効にし、必要に応じて優先順位を上げます。

## 設定

| 設定 | 既定値 | 内容 |
| --- | --- | --- |
| 同期歌詞のみを取得する | 有効 | `syncedLyrics` を持つ結果だけを `.lrc` として保存します。無効時は非同期歌詞も `.txt` として保存します。 |
| 歌詞を取得する条件 | `.lrc`／`.txt`／埋め込み歌詞がない | 同名の `.lrc` のみがない場合／同名の `.lrc` または `.txt` がない場合／同名の `.lrc`・`.txt` と埋め込み歌詞がない場合、の 3 種類から選びます。非同期歌詞を残して同期歌詞を取得するには、`.lrc` のみがない場合を選択します。 |
| 埋め込み歌詞の処理 | 無視 | `無視` は既存タグを変更しません。`削除` は検索前に Lyrics タグを削除します。削除できない場合は取得を中止します。`上書き` は既存タグがあっても検索し、取得した歌詞を Lyrics タグへ保存します。保存できない場合はログに記録します。 |
| 候補が複数ある場合は選択画面を表示する | 有効 | メタデータ検索で特定できず複数候補が見つかった場合に、曲名・アーティスト・アルバム・長さ・同期の有無を表示して保存する歌詞を選べます。 |
| 既存の歌詞ファイルを上書きする | 無効 | 有効にすると、既存の `.lrc`／`.txt` も検索結果で置き換えます。 |
| プラグイン設定ポップアップのテーマ | Windows の設定に同期 | Windows のアプリテーマに合わせるほか、ライトモードまたはダークモードを固定できます。 |
| プラグインの言語 | 自動 | 「自動」では日本語環境で日本語、それ以外の環境で英語を使用します。英語または日本語に固定することもできます。 |

設定は MusicBee のプラグイン画面にある「プラグイン設定」から変更できます。設定ファイルは MusicBee のプラグイン永続ストレージに `LrclibLyrics.settings.json` として保存されます。

## ビルド

1. Visual Studio 2022 で `MusicBee.LrclibLyrics.sln` を開きます。
2. **.NET desktop development** ワークロードと .NET Framework 4.8 Developer Pack を利用可能にします。
3. `Release | Any CPU` をビルドします。

MusicBee は 64-bit Windows 上でも 32-bit プロセスとして動作するため、依存するネイティブ DLL を追加する場合は x86 互換性に注意してください。本プラグインはマネージド DLL のみです。

## リリース作成

GitHub Actions の Build artifact は `mb_LrclibLyrics-v<バージョン>-<短縮コミット ID>.zip` という名前で作成します。Release workflow は `v*` タグの push で起動し、タグは `vX.Y.Z` 形式である必要があります。ビルドした DLL の Assembly version と File version がタグのバージョンに一致しない場合、workflow は失敗し、GitHub Release は作成されません。一致した場合は `mb_LrclibLyrics-vX.Y.Z.zip` を作成して GitHub Release に添付します。ZIP には `mb_LrclibLyrics.dll` と `LICENSE` のみを含みます。
